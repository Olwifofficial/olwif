# Merriweather Regular

Unmodified WOFF2 Latin and Latin Extended subsets, weight 400, normal style,
downloaded from Google Fonts on 2026-09-24. Served locally; no runtime requests
to Google Fonts are needed. Other writing systems fall back to system serif fonts.

Official stylesheet: https://fonts.googleapis.com/css2?family=Merriweather:wght@400&display=swap

Upstream family: https://github.com/google/fonts/tree/main/ofl/merriweather
